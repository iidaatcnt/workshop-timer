# Workshop Timer (Pomodoro App)

ワークショップや日々の作業に集中するための、直感的でかわいらしいポモドーロタイマーアプリです。
「Pomodoro（集中）」と「Basil Break（休憩）」の2つのモードを切り替えながら、美味しい時間を育てましょう🍅🌿

## 使い方

1. **タイマーの開始/停止**
   - 中央下部の「再生/一時停止」ボタンを押してタイマーを操作します。
2. **モードの切り替え**
   - 画面下部のスキップボタン（右向き矢印）で、「Pomodoro（集中）」と「Basil Break（休憩）」のモードを手動で切り替えられます。
3. **時間の変更**
   - 中央のタイマー（トマト/バジル）の左右にある `+` `-` ボタンを押すことで、**現在開いているモード**の時間を1分単位で調整できます。
4. **Auto Loop（自動ループ）機能**
   - 画面最下部の「Loop」トグルスイッチをオンにすると、時間がゼロになった際に自動で次のモード（ワーク⇔休憩）に切り替わり、カウントダウンが止まらずに進行し続けます。オフの場合は、手動で再生する必要があります。
5. **メッセージの変更**
   - 画面上部の入力欄（「ヤルまたはめちゃヤル」など）は自由に変更でき、いまのタスクや目標を入力してモチベーションを高めることができます。

## 開発・起動方法

```bash
# パッケージのインストール
npm install

# 開発用サーバーの起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) にアクセスするとアプリが確認できます。
